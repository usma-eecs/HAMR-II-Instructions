Task 7: Install the Raspberry Pi

Mount the Raspberry Pi on the sensor-suite base plate before the superstructure is attached.

Parts required

  • Prepared Raspberry Pi Zero 2 W
  • Raspberry Pi mounting kit
  • Four M2.5 × 4 mm nylon spacers
  • Four M2.5 × 8 mm socket-head screws
  • Issued microSD card when directed

Tools required

  • 2.0 mm Allen key

Steps

  1. Place one M2.5 nylon spacer over each of the four brass heat-set inserts in the sensor-suite base plate.
  2. Record the Raspberry Pi identifier if your section tracks serial numbers.
  3. Place the Raspberry Pi on top of the spacers in the reference orientation, with the front of the aircraft toward the CSI camera connector end of the board.
  4. Start all four M2.5 × 8 mm mounting screws by hand before tightening any one screw.
  5. Snug the screws with the 2.0 mm Allen key in a crisscross pattern. Tighten only until the board is secure.
  6. When directed by faculty, insert the prepared microSD card into the Raspberry Pi. The microSD card is a tool and must be recovered at the end of the lesson.
STOP! Ask for a faculty member to verify Raspberry Pi orientation and screw engagement before you continue to cable connections and final sensor-suite installation.

Common errors

  • Mounting the Raspberry Pi directly to the base plate without the spacers.
  • Using the wrong Allen key on the M2.5 mounting screws.
  • Twisting the board by tightening one corner fully before the other three screws are started.
  • Inserting the microSD card backwards or at an angle.
  • Leaving the issued microSD card in circulation at the end of the lesson.
