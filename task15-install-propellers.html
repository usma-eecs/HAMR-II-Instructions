Task 15: Install propellers

Install the correct CW and CCW propellers after motor testing is complete.

Parts required

  • Vehicle with motors installed and tested
  • Propeller package
    • Four Gemfan LR 7035 2-blade propellers
    • Four M8 nylon-insert lock nuts

Tools required

  • M8 nut driver

Step 1. Match each propeller to the correct motor

  1. Remove the four propellers and four M8 nylon-insert lock nuts from the propeller packaging.
  2. Hold each propeller with the label side facing up.
  3. Identify the thicker leading edge and the sharper trailing edge.
  4. Install each propeller on the motor that spins in the matching direction from Task 14.
Propeller map. Match CW and CCW propellers to the verified motor directions.

Step 2. Secure the propellers

  1. Seat each propeller fully on the motor shaft.
  2. Thread each M8 lock nut on by hand first.
  3. Use the M8 nut driver to snug each nut. Do not overtighten.
  4. Check that every propeller sits flat with no wobble or play.
STOP. Ask a faculty member to verify propeller orientation before the first prop-on run.
Label side up.
The printed side of each propeller faces upward when installed.

Common errors

  • Installing a propeller upside down with the label side down.
  • Putting a CW propeller on a CCW motor or vice versa.
  • Not seating the propeller fully before tightening the nut.
  • Leaving a propeller nut only finger-tight.
