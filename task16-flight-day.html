Task 16: Flight Day

Run the final handoff checks before a prop-on run or flight event.

Parts required

  • Completed aircraft

Tools required

  • Faculty verification

Flight-day handoff checklist

Before an aircraft is handed off for its first prop-on run or flight event, confirm the items below.

CheckWhat good looks like
AirframeNo missing fasteners, no visibly cracked printed parts, no loose arms, and no loose FC/ESC stack hardware.
WiringCamera ribbon fully seated, GPS cable connected to GPS, FC/RPi cable connected to TELEM, and no loose wires in the propeller arc.
SoftwareMission Planner installed, frame type confirmed, preset parameters loaded, sensor calibration completed, and motor check completed.
PropellersCW and CCW propellers match the verified motor directions and all propeller nuts are snug.
Issued itemsThe issued microSD card and any borrowed tools are accounted for.
STOP. Do not proceed to a prop-on test or flight event until a faculty member verifies the completed aircraft.

Common errors

  • Assuming software is correct without checking the motor-test results.
  • Leaving loose wiring where a propeller can strike it.
  • Proceeding to a prop-on run without faculty verification.
