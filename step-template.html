HAMR II Step-Writing Template

Use this page when you want to write a new task in the same style as the finalized manual.

Template for writing a task

Copy this structure when you need to add a new task or rewrite a weak section. Keep the wording direct, explicit, and bench-usable.

Task X: [Clear action title] Blocker [None] or Task Y: [Title] Task Z: [Title] Parts Required - [Exact part name] - [Exact fastener name] - [Any consumables] Tools Required - [Exact tool name] - [Exact driver size] - [Test equipment if needed] Purpose [One or two sentences explaining what the task accomplishes and why the orientation / order matters.] Steps 1. Retrieve [exact parts] and place them on the bench. 2. Confirm orientation: [front / rear / top / bottom / arrow direction / contact direction]. 3. Hand-start [exact fastener] before using tools. 4. Tighten with [exact tool] in a crisscross / catty-corner pattern until [clear stop condition]. 5. Route [cable / harness] through [exact path] and confirm it is not pinched or under tension. 6. Verify [what the finished result should look like]. STOP! Ask for a faculty member to verify your work before proceeding. [Use this only where a mistake can damage hardware, create a polarity problem, or make the next step unsafe.] Common Errors - [Actual mistake cadets make] - [Wrong orientation] - [Wrong fastener or wrong tool size] - [Overtightening / cross-threading / pinched cable]

Template for writing a single step

[Action verb] + [exact object] + [orientation or location] + [tool / fastener if needed] + [stop condition] Example: Install the four M3 × 12 mm socket-head screws from the underside of the sensor suite superstructure, then hold each screw with pliers while you start the lock nuts by hand from above.

Good single-step example

Route the camera cable into the camera module with the metal contacts facing away from the black retainer, then close the retainer only after the cable is seated fully and evenly.

Why this works

  • It names the exact hardware.
  • It gives the cable orientation explicitly.
  • It tells the reader what “correct” looks like before they move on.
  • It avoids vague words like “attach” or “put it in there.”
