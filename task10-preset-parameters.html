Task 10: Load preset parameters

Load the current faculty-issued preset parameter file after the aircraft is fully wired.

Parts required

  • Completed aircraft without propellers

Tools required

  • USB-C cable
  • PC running Mission Planner

Steps

  1. Download the current preset parameter file from the course Teams page.
  2. Connect the flight controller to the PC and open Mission Planner.
  3. Reconnect to the FC at 921600 baud.
  4. Open CONFIG → Full Parameter List and select Load from file.
  5. Select the current preset parameter file and acknowledge the confirmation dialogs.
  6. Select Write Params and confirm the write operation.
  7. Disconnect and reconnect USB-C so the FC reboots, then reconnect in Mission Planner.
STOP! If Mission Planner throws unexpected parameter warnings or the wrong file is selected, stop and ask for a faculty member before writing anything.

Common errors

  • Loading the file but forgetting to select Write Params.
  • Using an old parameter file instead of the current one for the course.
  • Skipping the reboot after writing the parameters.
  • Selecting the wrong COM port and assuming the FC is unresponsive.
