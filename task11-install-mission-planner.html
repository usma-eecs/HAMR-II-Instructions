Task 11: Install Mission Planner

Download and install Mission Planner on the PC.

Parts required

  • No aircraft hardware required

Tools required

  • PC with internet access

Steps

  1. Open the official Mission Planner installation page.
  2. Download the latest Mission Planner installer.
  3. Run the installer and follow the prompts.
  4. If Windows prompts for driver installation, accept the prompt and continue.
  5. Launch Mission Planner when the installation completes.
Altitude Angel.
If Mission Planner prompts you to sign in to or register for Altitude Angel, do not register. Close or dismiss the prompt and continue with the course procedure.

Common errors

  • Downloading Mission Planner from an unofficial source.
  • Closing the installer before the driver prompts complete.
  • Assuming Mission Planner is ready without launching it once after installation.
  • Registering for Altitude Angel even though it is not required for this course.
